## E1 — effects: what we know (2026-11-14)

Not a Remix limitation: our proxy leaves them out.
- `checks/live_capture.h:1693-1724`: draws whose pixel shader declares the effect buffers t27/t30 (particles, smoke,
  distortion; `declares_effect_buffers`) are dropped. They reached Remix as solid cutout geometry, so the user decided
  on 2026-11-01 to leave them out. `NIER_REMIX_LIVE_EFFECTS=1` keeps them (as the solid geometry).
- The Remix image replaces the game's whole frame; only the HUD (blended draws into the final image) is replayed over
  it. The game's own effects are therefore lost twice: not in Remix's scene, and not composited back.
- Effects drawn into other targets (a reduced-size particle buffer, if NieR uses one) are dropped earlier by the
  scene-target filter (`live_capture.h:1666`).

Directions to test, cheapest first:
1. **Composite the game's effects over the Remix image,** like the HUD: replay the effect draws (and any particle
   buffer's composite) onto the Remix frame, depth-tested against the game's own depth buffer (same camera). Keeps
   the game's exact look, including distortion and soft particles. The game still renders its scene, so its depth
   exists.
2. **Translucent / emissive Remix materials** for the simple cases (additive sparks, glows), so they light the scene.
3. Keep the solid-geometry path only as a diagnostic.

First step: list every effect shader in the camp and desert captures with its blend state, target and draw count
(the shader table `remix: shader ... effect=` already counts them), and record what each one is.
