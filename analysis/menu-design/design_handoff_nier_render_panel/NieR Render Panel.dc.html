IMGUI IMPLEMENTATION NOTES
  1. One Begin() window, NoTitleBar | NoResize | NoCollapse | NoSavedSettings. Pos = (display.x − 32 − w, 32). Max height = display.y − 64.
  2. Layout: header, then BeginChild("body") with height = avail − footerHeight (scrolls), then the footer, which always stays visible.
  3. Scale: rebuild the font atlas at 15 × DPI scale and call style.ScaleAllSizes(). Read DPI from Win32 so it works the same on Windows and Proton. Bundle the fonts; never look up a system font.
  4. Keep three separate values: active (fixed at startup), saved (on disk), edited (in memory). dirty = edited ≠ saved. Save writes only saved. startupError is cleared only by a restart.
  5. Combo: BeginCombo with two Selectables. Show Custom75 with ImGuiSelectableFlags_Disabled when the capability is not validated, with the reason as a second line.
  6. Disabled buttons: BeginDisabled() plus border-only style overrides. Feedback is one drawn rect plus text. The ✕ △ ↻ ⊘ glyphs must be merged into the atlas.
  7. Input: enable NavEnableKeyboard while open and swallow game input. Insert toggles; Esc closes the open combo first, then the window. Closing does no I/O. When closed, submit nothing: no HUD stub.
  8. Fill backend/platform/dimensions from runtime probes. Show “unknown” / “—” until observed. Never derive them from OS or GPU vendor.
